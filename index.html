👋 Panduan Pengguna Baru

Baru pertama kali di Alvskywok 2.0? Ikuti langkah mudah berikut.

  1. Daftar akun: isi username 3–24 karakter (huruf, angka, garis bawah) dan password minimal 10 karakter, lalu tekan Daftar.
  2. Login: setelah akun dibuat, masukkan username dan password yang sama lalu tekan Login.
  3. Jelajahi website: buka Roblox Script Library untuk mencari script berdasarkan nama game, gunakan AI Helper untuk bertanya, dan baca pengumuman admin.
  4. Butuh bantuan? kirim komentar atau laporkan bug melalui formulir di bagian bawah halaman.

Tips keamanan: gunakan password unik, jangan bagikan password atau data pribadi, dan jangan menjalankan kode Roblox dari sumber yang belum kamu percaya.

⚠️ Website belum terhubung ke server

Kamu sedang membuka file HTML secara langsung atau server backend belum aktif. Login dan Daftar hanya berfungsi setelah website dipublikasikan melalui alamat HTTPS dari hosting. Membuka file dari penyimpanan HP (content:// atau file://) tidak dapat menghubungkan API login.

Admin perlu menjalankan backend Node.js dan membuka website dari URL hosting, bukan dari file HTML lokal.
